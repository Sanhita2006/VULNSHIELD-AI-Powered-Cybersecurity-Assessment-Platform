Actionable Device & Browser Hardening

Demo
Recommended

1. Enable Global Privacy Control

Broadcast the Sec-GPC header signal to legally require websites and ad brokers to refrain from selling or sharing your personal browsing footprint.

Action: Enable GPC in Brave, Firefox, DuckDuckGo, or via privacy extensions.
High Priority

2. Enforce Strict HTTPS-First Mode

Configure your browser to automatically upgrade all HTTP navigation requests to encrypted HTTPS, preventing passive Wi-Fi eavesdropping.

Action: Turn on 'Always use secure connections' in browser settings.
Good Practice

3. Audit Site Permissions & WebRTC

Regularly revoke unused camera, microphone, and location permissions. If using a VPN, ensure WebRTC mDNS masking prevents real IP leakage.

Action: Review permissions under chrome://settings/content or about:preferences.

Browser Sandbox Boundaries — What Web Applications Cannot Check

Honesty in cybersecurity: Modern web browsers strictly isolate web code from operating system internals.
